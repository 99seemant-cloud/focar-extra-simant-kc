# FoCar Extra Assignment

## Project Description

This project implements a rectangular route using the FoCar robot and Raspberry Pi Pico W.

## Features

- Drives along a rectangular route.
- Stops at each corner.
- Flashes the onboard LED three times at each corner.
- Turns 90 degrees at each corner.
- Returns approximately to its starting position.

## Project Files

- focar.py: Motor and LED control functions.
- main.py: Main rectangular route program.

## Hardware

- Raspberry Pi Pico W
- FoCar robot
- Two DC motors
- Onboard LED

## Programming Language

Python (MicroPython)
